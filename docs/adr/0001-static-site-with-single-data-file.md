# 0001：純靜態網頁，內容集中在一個資料檔

日期：2026-11-15
狀態：已採用

## 背景

網站只有幾個部分（入坑必看、成員簡介、精選年表），用 GitHub Pages 免費架設。站主平日要上班，希望臨時想改推薦語或換影片時可以自己動手，不必每次都透過 Claude，也不想因為改字而弄壞版面。資料之後還要從精選版一路補成完整版。

## 決定

- 用最單純的靜態網頁（HTML、CSS、少量 JavaScript），不使用框架，沒有建置步驟。
- 所有內容（必看影片、推薦語、之後的成員和年表）集中放在一個資料檔，和版面的程式碼分開。
- 站主可以直接在 GitHub 網頁上編輯資料檔，存檔後網站自動更新；也可以交給 Claude 改。
- 新增一筆內容就是在資料檔裡多加一筆。

## 考慮過但沒採用的做法

- **所有修改都透過 Claude**：每個小修改都要等，站主無法自己處理。
- **接有後台的內容管理系統**：對只有幾頁的網站太重，多一個要維護、可能壞掉的系統。

## 後果

- 內容由瀏覽器讀取資料檔後顯示，資料檔格式寫錯時頁面會顯示不出內容，所以要有清楚的格式範例，並在頁面上給出看得懂的錯誤提示。
- 如果之後頁面變多、需要每頁獨立網址或搜尋引擎優化，可能要改用靜態網站產生器，屆時資料檔可以沿用。
