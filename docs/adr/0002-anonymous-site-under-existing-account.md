# 0002：網站匿名，但沿用現有的 GitHub 帳號

日期：2026-11-15
狀態：已採用

## 背景

網站完全公開，但站主要求完全匿名：頁面上不署名、不放暱稱、不放任何個人資訊。免費的 GitHub Pages 需要公開的 repo，網址和 repo 頁面都會顯示帳號名稱 `wis2ria`。

## 決定

- 沿用現有帳號，網址是 `wis2ria.github.io/ateez-atiny`，表單編輯器也用這個帳號登入。
- 帳號名稱視為代號，不算個人資訊，可以露出。
- 網站頁面本身不出現任何署名或個人資訊。
- commit 的作者資訊不可帶個人信箱。

## 考慮過但沒採用的做法

- **另外買網域**：只遮住網址，repo 頁面仍看得到帳號，每年要付費。
- **另開一個專用的 GitHub 帳號**：能把網址和 repo 都切開，但要多管一個帳號。

## 後果

- 如果之後 `wis2ria` 這個名稱被用在能連到本人的地方，匿名就會失效，屆時要重新考慮另開帳號。
- 站主自己在 GitHub 網頁或編輯器上儲存時，commit 會帶帳號的信箱設定，上線前要確認帳號已開啟隱藏信箱的設定。
